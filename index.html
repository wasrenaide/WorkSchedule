일월화수목금토

버전 0.2.0

모드 맨 오른쪽 버튼으로 계획 → 실행 → 계산 순서로 바뀌어요.

계획
· 날짜를 누르면 시간이 바뀌어요. 평일 7~13, 주말 쉼·8·10·11·6.
· ▲ 올림 / ▼ 내림 버튼으로 누르는 방향(숫자, 운동 칸)을 바꿔요.
· 운동 칸(평일, 휴일이 아닌 토요일): 운동함 → 회식 → 운동안함(토요일은 회식 없이 운동함 ↔ 운동안함). 회식은 8시간 고정, 운동 횟수에 안 세요. 운동일은 최대 12시간.
· 연차·교육: 켜고 평일을 누르면 연차 → 교육(8시간) → 해제. 주말·공휴일은 없어요.
· 수기입력: 돌림판으로 직접 고르고, 휴무·쉼·자동으로 되돌릴 때도 써요.
· 자동 시간은 기본 11시간(운동일 10). 넘치면 말일부터 줄이고, 모자라면 오늘 이후 가까운 날부터 13시간(운동일 12)으로 올려요.
· 운동은 기본 7일을 넣어 주고, 7일 미만이면 빨갛게 경고해요.
· 달력 배경: 최대 시간 미만 초록, 초과 빨강, 딱 맞으면 흰색.
· 주 52h / 64h: 제목 옆 버튼을 누르면 확인 후(한 번 더) 바뀌어요. 52시간제 최대 208·215·222·230, 64시간제 256·265·274·283(28·29·30·31일, 29일은 임시값). 모든 기기에 같이 적용돼요. 바꿔도 칸의 값은 그대로이고, 최대 옆 맞추기 버튼을 누르면 새 최대에 맞춰 자동 계산해요.
· 패데: 21일이 속한 주 금요일(공휴일과 겹치면 전주 금요일).

실행
· 지난 날은 계획대로 채워져 있어요. 다르면 눌러서 시·분을 고쳐요.
· 요약: 예상 합계, 최대와의 차이(+는 초과), 운동 횟수.

계산
· 출근·퇴근 시각을 누르면 돌림판이 열려요. 체류시간 4:30 이상 30분, 9:00 이상 1시간이 자동으로 빠지고, 제외시간은 그 위에 추가로 빼요.
· 차감이 커지면 빨강, 작아지면 초록으로 깜빡여요.

표시 시간 색은 짧으면 초록·길면 빨강, 토요일 파랑, 일요일·공휴일 빨강, 오늘은 검정 칸 테두리, 오렌지 테두리는 기록해 둔 출근 현황(오늘부터 3개월)과 지금 근무표가 달라진 날. 실제 기록은 공유 저장소에 저장돼요.

아래 버튼
· 설명: 이 설명을 열고 닫아요.
· 캘린더 업데이트(맨 아래): 맥북 캘린더 `출근`에 반영한 마지막 시각을 보여줘요(오늘 포함 이번 달부터 3개월). 근무표와 같으면 버튼이 꺼지고, 달라지면 오렌지색이 되며 달라진 날은 달력에 오렌지 테두리가 떠요.
· 수정 지우기: 오늘부터 내가 고친 시간·운동만 지워 자동 계획으로 되돌려요. 실제 기록은 그대로예요.
· 월 초기화: 오늘부터의 계획 수정과 기록을 지워요. 오늘 이전 기록은 초기화·52/64 전환에도 그대로 남아요.
· 지우는 버튼은 두 번 눌러야 실행돼요(처음에 ‘한 번 더!’).
· 자동·라이트·다크: 누를 때마다 화면 색이 바뀔요. 자동은 기기 설정을 따라가고, 이 기기에만 저장돼요.
